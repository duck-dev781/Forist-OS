# Contributing to Forist OS

Thanks for your interest in Forist OS. The project is in an early planning and prototyping stage.

## Before submitting changes

1. Check existing issues and pull requests to avoid duplicate work.
2. Keep changes focused and explain the motivation.
3. Do not claim a feature works on hardware unless it has been tested and the test environment is described.
4. Never commit passwords, tokens, signing keys, private user data, or proprietary firmware.
5. Respect upstream licenses and document third-party components.

## Areas to help

- Desktop interface and accessible design
- ChromiumOS/openFyde build research
- Kernel, graphics, audio, Wi-Fi and Bluetooth compatibility
- Secure update and recovery design
- Linux application integration
- Android runtime feasibility
- Documentation and automated checks

## Pull requests

Include a concise summary, testing performed, known limitations, and screenshots for UI changes where useful. Changes that affect boot, partitioning, updates, authentication, or security should include a threat/rollback discussion.

## Licensing

By contributing, you agree that your contributions are submitted under the repository's MIT license unless you explicitly state otherwise and maintainers agree to another arrangement. Third-party components keep their own licenses.
