Open the repository's Build Forist v86 test image workflow. Run it with Run workflow, wait for it to finish, then download the forist-v86-test-image artifact and extract the ZIP. Choose forist-v86-test.img below.

Your Forist test machine will appear here.Select the generated disk image, then boot it.

Important · Experimental build

This first image is a minimal 32-bit Linux boot test for v86. It is not yet the Forist graphical desktop and does not contain Chromium, Android, Google Play, or a production updater. This page runs an emulator inside your browser; it does not install or change your laptop's operating system.

The emulator library and BIOS are loaded from copy.sh over HTTPS. A selected disk image stays in this browser tab and is passed to the emulator; this page does not upload it to the Forist repository.
